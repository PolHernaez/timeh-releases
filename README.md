# TimeH

App d'alarmes per a Android que et pregunta el vespre si demà vas a l'oficina i programa sola les alarmes que toquen.

**Descàrrega:** l'última versió és a [Releases](../../releases/latest) (`TimeH.apk`). L'app s'actualitza sola des d'aquí.

Aquest repositori només conté els instal·ladors. El codi és privat.
